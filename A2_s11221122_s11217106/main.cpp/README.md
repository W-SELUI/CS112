======================================================================



#### **Files included**

* main.cpp file
* Readme file
* Mark allocation sheet
* books.txt
* main (visual studio version)
* Library.h
* Node.h
* Book.h



#### **Description**

This program manages the book records of the USP library by using Linked Lists and classes. This allows the user to:

* Read from the txt file
* Store data in a linked list of book objects
* Get ID's, titles and copies
* Able to read whether the book is available or out of stock 
* Display statistics about the books



#### **How to run**:

1. Open Visual Studio and load main.cpp.
2. Place books.txt in the same folder as the executable/project.
3. Run the program.





###### Use the menu options to:

1. Display all books for the menu
2. Update copies of books in the menu
3. Print current status of the menu 
4. Exit

 

#### Notes/Detailed information:

* Program replaces structs and arrays with classes and linked lists. This ensures that the program grows and shrinks dynamically.
* The link list ensures the collection of books in memory are managed efficiently 
* A function was used to calculate the availability of copies (in stock or out of stock).
* Input validation was implemented
* library books updated without any issues
